# 🏴‍☠️ The Straw Hat Journey: One Piece Timeline

> "Inherited will, the destiny of the age, and the dreams of the people — as long as people continue to pursue the meaning of freedom, these things will never cease to be." — **Gol D. Roger**

Welcome to **The Straw Hat Journey**, an immersive, narrative-driven interactive timeline of the voyage of Monkey D. Luffy and his crew. From the humble beginnings in East Blue to the earth-shattering events of the Final Saga, this project chronicles the path toward the title of Pirate King.

---

## ✨ Features

- **🚢 Immersive Saga Timeline**: A chronological voyage through every major saga and arc of the series, featuring high-fidelity visuals and curated descriptions.
- **📜 Navigator's Log**: Character-driven insights and personal reflections from the crew (Luffy, Nami, Robin, and more) integrated directly into the timeline.
- **🥁 Drums of Liberation**: Experience the rhythmic atmospheric resonance of the Joy Boy awakening in the later chapters.
- **🗿 Poneglyph Lore**: Interactive ancient stones scattered throughout the timeline, holding the secrets of the Void Century.
- **💎 Premium Aesthetics**: Custom-built with a "Grand Line" design language, featuring Haki-inspired animations, golden glows, and a responsive dark-mode interface.
- **🧭 Saga Navigation**: Quick-jump navigation to sail between major eras of the journey.

---

## 🛠️ Tech Stack

This project is built with modern web technologies to ensure a performant and cinematic experience:

- **Framework**: [Astro](https://astro.build/) (Static Site Generation)
- **Styling**: Vanilla CSS (Custom Design System)
- **Logic**: Vanilla JavaScript (Interactive Animations & Effects)
- **Assets**: Curated high-resolution imagery and icons.

## 🚀 Getting Started

To set sail and run this project locally, follow these steps:

### 1. Prerequisites
Ensure you have [Node.js](https://nodejs.org/) (**v22.12.0 or higher**) and [pnpm](https://pnpm.io/) installed.

### 2. Installation
Clone the repository and install the dependencies:
```bash
pnpm install
```

### 3. Development
Start the local development server:
```bash
pnpm dev
```
The application will be available at `http://localhost:4321/one-piece-timeline/`.

### 4. Build
To create a production-ready bundle:
```bash
pnpm build
```
The output will be in the `dist/` directory.
